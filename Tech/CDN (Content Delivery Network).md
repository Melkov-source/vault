**CDN** — это сеть геораспределённых серверов, предназначенных для доставки контента.
Доставка происходит с минимальной задержкой, за счёт кэширования и маршрутизации запросов к ближайшему узлу.

| Название            | Описание                                                           |
| ------------------- | ------------------------------------------------------------------ |
| Cloudflare          | бесплатный план, edge functions (Workers), отличная защита.        |
| Fastly              | высокая производительность, сложная конфигурация, edge-компьютинг. |
| Akamai              | дорогой, но один из лидеров по скорости и масштабам.               |
| Amazon CloudFront   | интеграция с AWS, высокая надёжность.                              |
| Google Cloud CDN    | хорош для гугловской экосистемы.                                   |
| Microsoft Azure CDN | для проектов в Azure.                                              |
| Vercel              | автодеплой, CDN встроен, edge functions, хорош для SSR/ISR.        |
| Netlify             | аналогично, для Jamstack-подходов.                                 |
| Bunny.net           | дешёвый, но мощный CDN с edge storage.                             |
| jsDelivr / UNPKG    | для npm-пакетов                                                    |

1. Настроить кеширование
   -  CDN Invalidation: ручное удаление кеша при обновлении файлов.

   - `ETag`: сервер возвращает уникальный хеш ресурса. Браузер при повторном запросе шлёт `If-None-Match`.

   - `Cache-Control`: задаёт правила хранения (`no-cache`, `max-age` (Time To Live), `public`). Механизм, при котором CDN и браузер долго хранят файл в кэше, чтобы не загружать его заново.

2. Preloading / Prefetching
   Работает на уровне HTML и браузера, не требует CDN-функций.
   Подсказки браузеру заранее загрузить ресурсы, которые скоро понадобятся.
   - `<link rel="preload">` — говорит: "нужно срочно". Используется для шрифтов, важных JS-модулей.
   - `<link rel="prefetch">` — "может пригодиться позже", например, при переходе на следующую страницу.

3. Работа с MIME-типами
   Формальный способ сказать браузеру, какого типа файл он получает (например, JS, CSS, JSON). CDN или сервер добавляет заголовок `Content-Type`.
