TTL (Time To Live) — это **время жизни кеша**, то есть сколько времени CDN (или браузер) будет хранить копию ресурса, прежде чем снова запросить его с оригинального сервера.

Устанавливается через HTTP-заголовки, например:
```http
Cache-Control: public, max-age=86400
```
Значение `max-age=86400` — это 86400 секунд, то есть **1 день**.
