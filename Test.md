### **📌 Быстрый старт: Первые шаги**

1. **Установите необходимый софт:**
    - **Игровые движки:** Unity Hub, Cocos Creator
    - **Бэкенд и инфраструктура:** Docker Desktop, Node.js, VS Code (или ваша любимая IDE)
2. **Практическое задание: Сервер (NestJS)**
    - Пройдите официальный туториал NestJS.
    - **Цель:** Создайте простой REST API с одним модулем.
    - **Дополнительно:** Подключите его к локальной БД через Prisma и заверните всё в Docker-контейнер.
3. **Практическое задание: Клиент (Игровые движки)**
    - **Unity (WebGL):**
        - Соберите простейший WebGL-проект (например, с вращающимся кубом).
        - Реализуйте двустороннее взаимодействие: вызовите `console.log` в браузере из C# и сделайте кнопку в вебе, которая меняет цвет куба.
    - **Cocos Creator:**
        - Создайте новую сцену со спрайтом.
        - Напишите скрипт на TypeScript, который двигает этот спрайт по клику.
        - Изучите, как проект работает в браузере, используя Chrome DevTools.

### **⚙️ Серверная часть (Backend)**

#### **Фреймворк: NestJS**

- **Почему NestJS?** Перешли с Express для структуризации большой кодовой базы.
    
- **Преимущества:**
    
    - **Архитектура:** Четкая структура (модули, контроллеры, сервисы) из коробки.
        
    - **TypeScript:** Полная поддержка.
        
    - **Экосистема:** Множество готовых модулей (Redis, GraphQL, Prisma и т.д.).
        
- **Ресурсы:** [Официальный сайт](https://nestjs.com/) | [Документация](https://docs.nestjs.com/)
    

#### **Базы данных и ORM**

- **MySQL:** Основная реляционная БД для структурированных данных (пользователи, прогресс, инвентарь).
    
- **Prisma ORM:** Современный ORM.
    
    - **Плюсы:** Безопасность типов, интуитивный API, встроенные миграции.
        
- **Redis:** Используется как кэш и для pub/sub (сессии, временные данные, очереди).
    

#### **Инфраструктура и Деплой**

**Docker**  
Используется для создания предсказуемых сред.

- **Инструменты:**
    
    - **Dockerfile:** Инструкция для сборки образа приложения.
        
    - **Docker Compose:** Для определения и запуска многоконтейнерных приложений (app, db, redis).
        
- **Утилиты для управления:**
    
    - **Portainer:** Веб-интерфейс для управления контейнерами.
        
    - **Dozzle:** Просмотр логов контейнеров в реальном времени.
        

**Веб-сервер: Caddy**

- **Почему Caddy?** Простота настройки и автоматическое управление SSL-сертификатами (HTTPS). Идеален для быстрого развертывания и защиты staging-окружений.
    
- **Ресурсы:** [Официальный сайт](https://caddyserver.com/)
