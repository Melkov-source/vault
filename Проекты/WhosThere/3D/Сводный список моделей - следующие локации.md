# Сводный список 3D-моделей: следующие локации

Документ собран по сценарию `НЕПРОГЛЯДОВО_29 апреля_предфинал.md` и уже существующим спискам из папки `3D`.

Главная идея: квартиру Авдотьи считаем базовым готовым набором. Для квартиры Пелагеи, кухни Неверовых, подъезда и дороги не нужно заново делать весь советский быт. Переиспользуем модульную квартиру, модульный подъезд, кухонные пропсы, коридорные пропсы и часть мелочей, но меняем состояние, текстуры и настроение.

## Легенда

- **Reuse** - можно брать из уже сделанного ассета почти без изменений.
- **Variant** - нужна новая текстура, другой уровень чистоты/износа или небольшая геометрическая вариация.
- **New** - нужно моделить отдельно.
- **Optional** - нужно только если сцена попадет в билд или катсцену.

## 1. Квартира Пелагеи

Пелагея живет этажом ниже Авдотьи. Внешне ее жилье должно быть максимально уютным, чистым, "сказочно-бабушкиным": белые салфетки, живая герань, пироги, сервиз, аккуратность. Внутри этого уюта должны быть маленькие тревожные детали: чужой орнамент, кожаный шнурок, идол, закрытая дверь, ощущение стерильности и неестественного порядка.

Игрок, скорее всего, видит не всю квартиру. Нужны: входная дверь, небольшой коридор/проход, комната или кухня-гостиная со столом, окно с геранью, закрытая дверь в тайную комнату. Тайная комната может быть только дверью и звуком/светом, если внутрь нельзя попасть.

## 2. Кухня Неверовых, Ленинград

Сцена пролога происходит только на кухне. Камера сидит за столом, видны руки Марины, чашка, клеенка, край газеты и нижние/частичные силуэты родителей. Значит, нужна не полноценная квартира, а один убедительный кухонный угол с советской городской эстетикой.

В отличие от квартиры Авдотьи, это ленинградская интеллигентская семья: кухня тесная, жилая, не богатая, но более городская. Чуть лучше мебель, меньше провинциальной запущенности, больше следов семейного быта.

## 5. Психбольница / кадр Менгелеева

Эта локация нужна для плохой концовки и финального кадра. В концовке Б Марина оказывается в одиночной больничной камере: расфокус, препараты, стальная дверь, Менгелеев входит. В концовке В видна больничная палата: Менгелеев сидит на стуле в смирительной рубашке. Это не должна быть полноценная больница. Нужен один универсальный больничный набор, который можно собрать в две композиции.

Важно: сцену плохой концовки лучше держать визуально неэксплуатативной. Камера, дверь, кровать/кушетка, медицинская холодность, угроза через постановку и звук.

## Что точно можно переиспользовать из квартиры Авдотьи

| Группа | Использование |
|---|---|
| Модульная квартира | Стены, полы, потолки, дверные проемы, двери, плинтусы, окна. Для Пелагеи и Неверовых менять материалы и степень чистоты. |
| Кухонные пропсы | Плита, холодильник, мойка, шкафы, табуреты, чайник, кастрюли, чашки, тарелки. Для Неверовых и Пелагеи нужны более чистые варианты. |
| Коридорные пропсы | Вешалка, обувь, телефон, выключатель, зеркало. Для Пелагеи можно брать отдельные элементы, но меньше грязи и больше порядка. |
| Подъезд | Почти весь модульный набор нужен как есть. Добавить только конкретные двери, табличку ремонта, глазок, звонки, декали. |
| Атмосферные мелочи | Книги, рамки, шторы, батарея, розетки, выключатели. Менять текстуры и раскладку. |

## Приоритет производства

1. **Критично для ближайших сцен:** кухня Неверовых, дорога, базовый подъезд, дверь Авдотьи, дверь Пелагеи.
2. **Критично для Пелагеи:** стол с сервизом, пирог/варенье, герань, закрытая дверь, шнурок-артефакт, глиняная фигурка.
3. **Критично для концовок:** больничная камера, стальная дверь, кровать/кушетка, стул, смирительная рубашка.
4. **Опционально/усиление:** искаженные версии подъезда, зеленый свет Пелагеи, знак Непроглядова, внешний автобус.
