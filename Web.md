**Клиентская часть:**
1. Cocos Creator
   Игровой движок, заточенный под разработку в веб среде и с использованием веб стека.
   Документация: https://docs.cocos.com/creator/3.8/manual/en/
   
   Его удобнее всего использовать в контексте веба, потому что работа происходит непосредственно в нужно среде разработки. Удобно дебажить через DevTools.
   
   Однако движок не самый устойчивый и не редко возникают какие-то странные проблемы (по началу многое может быть странным и не очевидным). Например редактор не очень хорошо синхронизирует файлы и изменения в них, особенно если речь идет о системе префабов или мета информации файлов.
   
   Это основные языки на которых происходит разработка
	- Java Script / Type Script
	- CSS / Tailwind / HTML

1. Unity
   В данный момент это предпочтительный движок для разработки веб игр, однако он достаточно тяжелый в качестве решения, так как само ядро движка написано на C++, а скриптинг основан на C#. Все это дело компилируется сначала в il2cpp, после чего в WebAssembly для работы в среде JavaScript.
   
   Основная проблема использования заключается в том, каким образом скриптовая логика игры взаимодействует с веб окружением и наоборот. Для этого нам приходится писать некоторый мост между этими средами и обмениваться пакетами в виде json.
   
	- C#
	- Rollup / Terser
